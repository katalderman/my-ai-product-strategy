## The Prompt
Build me a web app prototype for an AI design copilot product called Shipframe.

Who: A product designer at a small SaaS team who also owns the marketing site,
working without a dedicated front-end developer.

Core task: The AI generates production-ready page layouts from the team's real
CMS content model and existing component library, not from a blank canvas.

First screen: A design canvas with a left sidebar showing a connected project:
CMS collections (Blog Posts, Case Studies, Team), a component library
(Navbar, Hero, Card Grid, Footer), and a deploy target badge (staging.acme.com,
status: live). Canvas starts with an empty "New page" frame.

AI moment: User selects the "Case Studies" collection and clicks "Generate
layout". The AI produces a full page design where every text and image element
is visibly bound to a real CMS field (title, client_logo, results_metric),
reuses the existing components, and flags one gap: "Case Studies has no
hero_image field. Add it, or use client_logo?"

Output: The generated page with a right-side "Bindings" panel listing each
element mapped to its CMS field, all green checkmarks except the flagged gap,
and a "Preview on staging" button showing the design is one click from deployed.

Clean UI. Dark theme. One page. No login.
